## Purpose
The **regulated-data foundation**: provenance everywhere. Without clean, versioned, license-aware data, both the science and the FDA evidence collapse.

## Candidate profile
- Data engineering (Python, SQL, orchestration), lineage/catalog tools.
- Cloud infra + GPU cluster management, Terraform/Kubernetes.
- Familiarity with scientific/omics data formats a plus.
